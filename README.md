# Project-PBO
OCMS-Mini adalah prototipe aplikasi perangkat lunak berskala kecil yang dikembangkan sepenuhnya menggunakan bahasa pemrograman Java. Proyek ini dibangun secara khusus sebagai tugas dan landasan fundamental untuk mata kuliah Pemrograman Berorientasi Objek (PBO) pada Semester 1. Aplikasi ini mendemonstrasikan pemahaman dasar mengenai logika
